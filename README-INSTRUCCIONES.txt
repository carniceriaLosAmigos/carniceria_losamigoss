PARA VER LA WEB
1. Instalar Node.js LTS en la computadora si todavía no está instalado.
2. Abrir esta carpeta y hacer doble clic en start.bat.
3. La primera vez instala las dependencias y crea el archivo .env.
4. Se abre el Bloc de notas con .env. Pegá tu clave privada de OpenAI después de OPENAI_API_KEY= y guardá.
5. Volvé a la ventana negra y esperá el mensaje "Los Amigos listo en http://localhost:3000".
6. Abrí Chrome y entrá a http://localhost:3000.
